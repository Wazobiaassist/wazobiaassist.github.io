# WazobiaAssist web page

Live at **https://wazobiaassist.github.io**. Ask questions about Nigeria by voice or text in Hausa, Igbo, Yorùbá or Nigerian English.

This repository only holds the published page. The code, including the source of this page (`app/static`), is at https://github.com/marshalwahlexyz1/wazobiaassist.

N-ATLaS is an initiative of the Federal Ministry of Communications, Innovation and Digital Economy, and powered by Awarri Technologies. WazobiaAssist is an independent entry to the National AI Innovation Challenge 2026, built on N-ATLaS.
